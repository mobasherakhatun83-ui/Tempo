# ⏳ Tempo — Study Timer & Alarm

Welcome to Tempo! A beautiful, distraction-free study timer, break cycle manager, and alarm clock designed to help you stay focused and productive. 🚀✨

---

## What is Tempo?
Tempo is a web app built to help students and professionals manage their study sessions and breaks effectively using soothing synthesized sounds and a clean, modern interface. 🎧🍅

---

## Key Features
* ⏱️ Smart Study Timer: Keep track of your study sessions and maintain deep focus.
* ☕ Break Cycles: Automatically manage short and long breaks to avoid burnout.
* ⏰ Alarm Clock: Get alerted with custom synthesized sounds when your timer ends.
* 🎨 Modern Design: Smooth animations and beautiful layouts built for comfort.
* 📱 Fully Responsive: Looks great and works smoothly on phones, tablets, and computers!

---

## How to Run It on Your Computer (Step-by-Step)

If you are new to coding, don't worry! Just follow these simple steps to run Tempo on your computer:

1. Download or Clone this repository to your computer.
2. Open your terminal or command prompt inside the project folder.
3. Install all the required tools by running this command:
   npm install
4. Start the app by typing:
   npm run dev
5. Open the link shown in your terminal (usually http://localhost:5173) in your web browser and enjoy! 🎉

## Built With (Technologies Used)
